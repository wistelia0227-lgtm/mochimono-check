持参品チェック（ショートステイ向け）
====================================

■ 開き方
  index.html をブラウザ（Edge / Chrome）で開くだけ。インストール不要、ネット接続不要。
  お試し：index.html?demo で開くと、サンプル入りの別領域で開きます（本番データには触れません）。

■ スマホ・タブレットで使う
  【お試し：家や事務所のWi-Fiで】 PCで phone_test.bat をダブルクリック → 出てきたURLをスマホのブラウザで開く。
      初回はWindowsのファイアウォールの確認が出るので「許可」。PCの窓を閉じると止まります。
  【本番：施設で毎日使う】 このフォルダを https のサイトとして置く（静的ファイルを置けるサービスなら何でも可）。
      スマホでそのURLを開き、「ホーム画面に追加」するとアプリのように起動でき、圏外でも開けます。
      置くのはアプリ本体だけ。利用者のデータはサイトには送られず、各スマホの中にだけ保存されます。
      本番で置く時は modules/devtools.js と index.html の該当1行を消してください。
  ※ データは端末ごとに別々です。複数の端末で同じデータを見ることはできません（移す時はバックアップのファイルで）。

■ 実験室（写真から持ち物を自動で読み取れるかを試す）
  設定 →「実験室」。この端末の中だけでAIを動かし、写真から品名と個数を読み取れるかを実機で確かめるページです。
  ・写真は端末の外へ出ません。最初にAIモデル（約2.9GB）を1回だけ入手します（Wi-Fiで）。
  ・https のアドレスで開いている時だけ動きます（http や file では「WebGPU: 使えない」と出ます）。
  ・画面下の「記録」に、端末の状態・かかった秒数・AIの答えがそのまま出ます。「結果をコピー」で写せます。
  ・試し終わったら「モデルを削除」で2.9GBを空けられます。普段の機能には影響しません。

■ 流れ
  1. 一覧 →「＋入所チェックを始める」→ 利用者と日程を選ぶ
  2. 入所チェック：品名をタップして足す（もう一度タップで＋1）。📷で写真。品名をタップすると特徴メモ。
     ・2回目以降の利用では前回の持参品が黄色で出ます。持参していれば「持参あり」、無ければそのまま。
     ・確認者を入れて「入所チェック完了」。黄色のまま残った品はリストから外れます。
     ・荷物を広げて「荷物全体の写真」を1枚撮ると、「この写真の上で品を囲んで登録する」が出ます。
       写真の上で品を指でなぞって囲む → 品名を選ぶ → 「この品を足す」。囲んだ部分がその品の写真になります。
       （実験室でAIモデルを入れてある端末では、「AIに品名を聞く」で品名・個数の候補が出ます。写真は端末の外へ出ません）
     ・「📷 続けて撮って足す」：アプリの中のカメラが開き、シャッターを押すたびに1枚保存されます（1枚に1種類）。
       「完了」を押すと、撮った順に写真を見ながら品名と個数を付けていけます。同じ品名は自動で1つにまとまります。
       途中でやめても「名前を付けていない品」として一番上に残り、後から続きができます。
       実験室でAIモデルを入れてある端末では、撮り終えると裏でAIが1枚ずつ調べ、名前を付ける画面に
       品名・個数・色の提案が自動で入ります（違っていたら直して決定）。写真は端末の外へ出ません。
       AIは「1枚に1種類」の写真が得意で、いろいろな物が混ざった写真は苦手です。
     ・個数は −／＋ のほか、数字そのものを押すと大きな数字ボタンで一度に決められます。
     ・品を外す：個数が1の時は「−」が🗑（外す）に変わります。数字ボタンの「0 外す」でも外せます（確認が1回出ます）。
     ・「👕 来所時の服装（任意）」：着てきた上着・靴・帽子など、荷物の一覧に入らない物を写真とメモで残せます。
       退所チェックの画面では来所時の記録と見比べながら「退所時の服装」を残せます。入れなくても完了できます。
     ・写真は「📷撮る」のほか、「🖼画像から」で端末に保存してある画像も使えます。
  3. 滞在中：途中で家族が持ってきた品は「途中で持ち込まれた品を足す」から。
  4. 退所チェック：現物と照らして「確認」。数が違えば −／＋ で実数に直す。
     ・緑＝一致　赤＝不足/多い　青＝消耗品が減った（正常）　白＝未確認
     ・合わない品があるまま完了すると、内容が「申し送り」として残り、次回の入所チェック画面の一番上に出ます。
  5. 「確認票を印刷」で、ご家族に渡す控え（写真つき・確認欄つき）が出ます。

■ 落とし物が出たら
  「持ち物検索」で品名や特徴（例：靴下 青）を入れると、誰の持ち物かが写真つきで出ます。

■ データの保存先（重要）
  データは「この端末の、このブラウザの中」だけにあります。他の端末とは共有されません。
  ブラウザの閲覧データ消去や端末の故障で消えるため、設定 →「ファイルに保存」で定期的にバックアップしてください。
  別の端末へ移す時も、保存したファイルを「ファイルから復元」で読み込みます。

■ 施設に合わせる
  設定 →「品目の一覧」で、タップで足せる品名・カテゴリ・消耗品の指定を変えられます。

■ 構成（開発者向け）
  js/       基盤（util / db=IndexedDB / master=品目初期値 / model=判定ロジック / app=画面切替と一覧）
  modules/  機能ごとに独立（stay / residents / search / settings / print）。scriptタグを外せばその機能だけ消える
  modules/devtools.js  開発用（サンプル投入・全削除・自己テスト）。本番で渡す時はこのファイルと index.html の該当1行を削除
  自己テスト：index.html?selftest で開くと画面下に結果が出ます
